# Remeny-Farm/.github

Default issue forms for every Remeny-Farm repository. GitHub shows them in each repository that has no `.github/ISSUE_TEMPLATE` folder of its own.

The forms follow the shared issue skeleton: Problem, Evidence, Expected and Done when; GitHub records the author, so a form needs no Source line. Each form sets a type, the `manual` source and the `triaged` status label from the shared label registry. Blank issues are off in the web form only. Agents and fleet lanes open issues through the API with the same skeleton; these forms are for people.

Change the skeleton and these forms together.
